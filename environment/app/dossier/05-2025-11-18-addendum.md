## Scheme decisions

### GW-017 - SUPERSEDED

GW-017 is reversed. Arrival order is not reproducible once a request has passed the load balancer, so repeated names produced intermittent signature mismatches. Canonical query ordering now sorts by NAME, then by VALUE, comparing the already-encoded text bytewise. No decoding happens before sorting.

_This replaces the GW-017 entry in the decision register. The register is not edited; this note is authoritative._
