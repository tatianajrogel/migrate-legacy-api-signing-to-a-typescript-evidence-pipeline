## Repeated query names

S. Varga traced the intermittent mismatches on the nightly export to repeated parameter names. Past the load balancer the order of repeated parameters is no longer the order the client sent. Umbrella asked for a change so that, for GW-HMAC-SHA256, query parameters are ordered by name and then by value, with each value percent-decoded before it is compared. Declined. The receiving parser normalises it anyway, so it made things worse.
